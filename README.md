# MECH 416: Introduction to Robotic Manipulators

An online, interactive textbook for MECH 416, built with [Jupyter Book](https://jupyterbook.org/).

Chapters currently published:

1. Introduction
2. Actuators for Robotics
3. Kinematics in 2D

More chapters are in progress and will be added as they're finished.

## Build locally

```bash
pip install jupyter-book
jupyter-book start
```
